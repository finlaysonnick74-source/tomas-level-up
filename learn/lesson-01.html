How websites really work, the tools behind them, and how you'll use AI to build them for local businesses — explained in plain English. First up: Code is a set of written instructions a computer can follow. Every website is made from three kinds of code, each with its own job.

Three big ideas to hold on to

1. A website is just a bunch of files, sitting on a computer that's always switched on.

2. Every change you make gets saved as a version, so mistakes can always be undone.

3. AI writes the code fast, but you are the builder who decides, checks and delivers.

The three languages

HTML skeleton

HTML (HyperText Markup Language) says what is on the page: a heading, a paragraph, a button. Things are wrapped in tags — labels in angle brackets like <h1>.

<!-- heading, text, button -->
<h1>Tomas Builds Websites</h1>
<p>Fresh sites for local businesses.</p>
<button>Get a quote</button>

CSS skin & clothes

CSS (Cascading Style Sheets) says how things look: colours, fonts, sizes, spacing. Each rule picks a thing, then lists its styles.

/* make it look good */
h1 { color: #FF5A36;
     font-size: 40px; }
button { background: black;
         color: white;
         border-radius: 99px; }

JavaScript brain

JavaScript (often just “JS”) says what happens when someone clicks, types or scrolls. It makes a page interactive.

// when the button is clicked…
const btn = document
  .querySelector("button");
btn.addEventListener("click", () => {
  alert("Thanks! Tomas will be in touch.");
});

Easy way to remember: if a website were a person, HTML is the skeleton, CSS is the skin and clothes, and JavaScript is the brain that makes it move. You'll rarely type all of this by hand — Grok Bot will write most of it — but knowing which part does what lets you ask for exactly the right change.
