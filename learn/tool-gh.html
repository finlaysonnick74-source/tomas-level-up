🧰 GitHub (and GitHub Pages)

What it is

A website that keeps your code safe online, with every version saved, plus free hosting for simple sites with GitHub Pages.

Why you’ll use it

Every change you make gets saved as a commit, so nothing is ever lost and you can always go back. It’s also where pros show their work.

Step-by-step setup

  1. Create your own GitHub account (GitHub accounts are for people 13 and over, so you’re good to go).
  2. Turn on two-step login to keep it safe.
  3. Make your first repo called tomas-web-studio, with a README that says what it’s for.
  4. Edit the README and make your first commit with a clear message.
  5. Turn on GitHub Pages in the repo settings and open your page at its github.io address.

👨 Account note

Free plan, and you can own this account yourself. Dad can be added as a collaborator so he can review your work.

🚀 Mini challenge

Make 3 small commits to your README (a heading, a sentence, an emoji) and find all 3 in the commit history.

✅ Ready when

You can show Dad GitHub working at the toolkit check at the end of Day 3.
