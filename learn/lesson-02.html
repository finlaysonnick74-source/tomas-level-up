5 · page built!
Step 1. You type tomasbuilds.com.au (just an example name) into your browser and press Enter. But computers don't use names — they use numbers.
Step 2. The browser asks DNS: “Where is tomasbuilds.com.au?” DNS looks it up like a phone book and answers: “It lives at 75.2.60.5”.
Step 3. Now the browser knows the address, so it asks that server: “Please send me the home page”.
Step 4. The server sends the files back: the HTML, the CSS, the JavaScript and the photos.
Step 5 · page built! The browser puts the page together from those files and shows it to you. All of that, usually in less than a second.

The words that matter

Browser — the app you use to visit websites, like Chrome, Safari or Edge.

Domain — a website's human-friendly name, like tomasbuilds.com.au (just an example name).

IP address — the number every computer on the internet has, like a phone number. Computers use these, not names.

DNS (Domain Name System) — the giant phone book that matches domain names to IP addresses.

Server — a computer that's always on and connected, whose job is to “serve” files to anyone who asks.

Host — the company that runs the server and keeps your site online, like Netlify. “Hosting” is the service they sell.
