❓ Quick quiz

1. What is a branch?

A safe copy of your project where you try changes without touching the main site.

2. What is a pull request?

A request to merge your branch into main, so someone can review it first.

3. Why must prices match the business plan?

So clients get honest, consistent prices, clearly marked as estimates.
