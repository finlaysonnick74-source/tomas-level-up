Web Basics · Lesson 11 of 11 · Look it up

Jargon buster.

Every techy word in this guide, in plain English. If a client uses a word you don't know, it's always fine to say: “Good question — let me check and get back to you.”

ABNAustralian Business Number; the ID number for a business in Australia.
AI buildera tool like Grok Bot that writes and edits code when you describe what you want.
Brancha side copy of a project for trying changes without touching the live version.
Briefa written description of what a client wants, by when, and for how much.
Browserthe app you use to visit websites (Chrome, Safari, Edge).
Buildwhen a host prepares your code for publishing.
Change controlkeeping track of every change to a project so you can see and undo it.
Codewritten instructions a computer can follow.
Commita save point in Git, with a message describing the change.
cPanelan older-style control panel for managing a hosting server.
CSSCascading Style Sheets; the code for how a page looks.
Deploy / deploymentpublishing a new version of a website to the internet.
DNSDomain Name System; the internet's phone book, matching names to IP addresses.
Domaina website's name, like example.com.au. You rent it yearly.
FTPFile Transfer Protocol; an old way to copy files straight onto a server.
Gitfree software that tracks every version of your project.
GitHuba website that stores Git projects online, with tools for teamwork.
Hand-overformally giving a finished site and its logins to the client.
Host / hostingthe company and service that keeps your website's files online.
HTMLHyperText Markup Language; the code for a page's structure.
HTTPSthe secure version of a web connection; shown by the padlock.
IP addressthe number that identifies a computer on the internet.
JavaScript (JS)the code for how a page behaves when you interact with it.
Live / productionthe real public website everyone sees.
Localon your own computer, visible only to you.
Mainthe main line of a project's history; what's on the live site.
Mergejoining a branch's changes into main.
Pluginan add-on that gives a WordPress site extra features.
Previewa private test copy of a site with its own link.
Pull request (PR)a request on GitHub to merge a branch into main, showing every change.
Pushsending your commits from your computer up to GitHub.
Registrara company that sells (rents out) domain names.
Repository (repo)a project folder tracked by Git, with its full history.
Roll back / revertgoing back to an earlier version that worked.
Serveran always-on computer that sends website files to visitors.
Static sitea site that sends the same files to every visitor. Fast and safe.
Tagan HTML label in angle brackets, like <h1>.
Versionone saved state of a project at a point in time.
Website builderan all-in-one, drag-and-drop tool that designs and hosts sites (Webflow, Shopify).
