📚 The lesson

Word of the day: Code: instructions written in a language a computer understands. HTML, CSS and JavaScript are the three languages of the web.

Web Basics lessons 1–6: what code is, how a website works, domains and hosting, hosting options, change control, and branches and pull requests.

  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.
  • GitHub: A website that keeps your code safe online, with every version saved.

💬 Talk it through with Dad

To finish the session, sit down together for a relaxed chat about today’s lessons. There are no wrong answers, it’s just a chance to put the ideas into your own words.

  1. In your own words, what do HTML, CSS and JavaScript each do on a page?
  2. When someone types a web address, what happens before the page appears?
  3. What's the difference between a domain and hosting? How would you explain it to Nan and Pop?
  4. Which hosting option would you pick for Tomas Web Studio, and why?
  5. Why is change control (saving versions with Git) such a big deal when you work on a real client's site?
  6. What's a branch and a pull request, and how could they keep a live site safe?

🛠️ Dive in (optional)

Keen to get your hands dirty? Whenever you feel like it, open your business site and start tinkering: change a heading, try a colour, ask Grok Bot to add a section. Totally optional, and the brief and real building start on Day 3.

🚀 Challenge

Explain one idea from today to Mum or Nan and Pop in under a minute, no jargon allowed!

❓ Quick quiz

1. What are the 3 languages of the web?

HTML for structure, CSS for style, JavaScript for behaviour.

2. What's the difference between a domain and hosting?

The domain is the address; hosting is the computer where the site's files live.

3. What is a commit?

A saved snapshot of your project with a short message saying what changed.
