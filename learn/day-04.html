❓ Quick quiz

1. What is a hex code?

A 6-character colour code like #FF5A36 so a colour looks the same everywhere.

2. What is a favicon?

The tiny icon in the browser tab.

3. Why do simple logos work best?

They're readable tiny on phones and big on signs, and easy to remember.
