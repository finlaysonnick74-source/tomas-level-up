📚 The lesson

Word of the day: Deploy: publishing the newest version of your code so people can see it.

What hosting and deploying are. Connect your GitHub project to Netlify and watch the first deploy run by itself.

  • Netlify: A host that puts your site online and updates it every time you push to GitHub.
  • GitHub: A website that keeps your code safe online, with every version saved.

❓ Quick quiz

1. What is hosting?

A computer that's always on and serves your site's files to visitors.

2. What is deploying?

Publishing the newest version of your code so people can see it.

3. What does auto-deploy mean?

Every push to GitHub updates the live site by itself.
