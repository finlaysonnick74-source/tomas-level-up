🧰 Cursor

What it is

A code editor with AI built in, where you open your project on your own computer.

Why you’ll use it

It lets you see all your files, read the code properly and make changes with AI help, then send them to GitHub.

Step-by-step setup

  1. Download and install Cursor.
  2. Sign in and connect it to your GitHub account.
  3. Clone your tomas-web-studio repo so it opens on your computer.
  4. Open the README, change a line, and commit and push it from Cursor.
  5. Check the change shows up on GitHub.
