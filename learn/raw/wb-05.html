04 · Hosting options compared

Where can a website live?

There are two main families. Code hosts publish the code you (and Grok Bot) write. Website builders are all-in-one: you design by dragging and dropping, and they host it too.

OptionWhat it isHonest notesCost
Code hosts — connect to GitHub, publish automatically
Netlify Your pickHosts sites straight from GitHub and rebuilds them every time you save a change.Very beginner-friendly. Gives a preview link for every change, free HTTPS, and simple contact forms built in. The free plan has usage limits — fine for small sites.Free starter plan; paid plans available. Check current pricing.
VercelVery similar to Netlify, made by the team behind a tool called Next.js.Excellent, especially for web apps. Watch out: its free “Hobby” plan is for personal, non-commercial use, so paid client work needs a paid plan.Free for personal use; paid for business. Check current pricing.
GitHub PagesFree hosting built into GitHub itself.Great for practice and a personal portfolio. Static sites only, no built-in forms, and GitHub says it isn't meant for running an online business or shop.Free with a GitHub account (public projects).
Cloudflare PagesHosting on Cloudflare's huge, fast global network.Generous free tier and very fast. Cloudflare is now steering new projects towards its “Workers” product, which is a bit more technical to set up.Free tier; paid add-ons. Check current pricing.
Website builders — all-in-one, drag and drop
WebflowA visual designer that writes the code for you, with hosting included.Beautiful, professional results, but there's a learning curve and the client pays a monthly site plan. Harder to move away from later.Paid site plans. Check current pricing.
WordPressThe most widely used website system in the world, with thousands of add-ons called plugins.The software (wordpress.org) is free, but needs its own hosting, and plugins need regular security updates. Many existing local sites use it, so you'll meet it. wordpress.com is a hosted version.Software free; hosting costs extra. Check current pricing.
ShopifyA builder made specifically for online shops.The best choice when a client sells products online: payments, stock and shipping all built in. Overkill for a simple business site.Monthly subscription plus payment fees. Check current pricing.

Tomas's rule of thumb

Brochure-style business site (cafe, plumber, surf school)? Grok Bot + GitHub + Netlify. Client wants to sell products online? Look at Shopify.

Chat about it

Prices change often. Together, look up today's free plan limits on Netlify. What would make a client need a paid plan?
