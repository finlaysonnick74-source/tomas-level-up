Jargon buster.

Every techy word in this guide, in plain English. If a client uses a word you don't know, it's always fine to say: “Good question — let me check and get back to you.”

ABN — Australian Business Number; the ID number for a business in Australia.
AI builder — a tool like Grok Bot that writes and edits code when you describe what you want.
Branch — a side copy of a project for trying changes without touching the live version.
Brief — a written description of what a client wants, by when, and for how much.
Browser — the app you use to visit websites (Chrome, Safari, Edge).
Build — when a host prepares your code for publishing.
Change control — keeping track of every change to a project so you can see and undo it.
Code — written instructions a computer can follow.
Commit — a save point in Git, with a message describing the change.
cPanel — an older-style control panel for managing a hosting server.
CSS — Cascading Style Sheets; the code for how a page looks.
Deploy / deployment — publishing a new version of a website to the internet.
DNS — Domain Name System; the internet's phone book, matching names to IP addresses.
Domain — a website's name, like example.com.au. You rent it yearly.
FTP — File Transfer Protocol; an old way to copy files straight onto a server.
Git — free software that tracks every version of your project.
GitHub — a website that stores Git projects online, with tools for teamwork.
Hand-over — formally giving a finished site and its logins to the client.
Host / hosting — the company and service that keeps your website's files online.
HTML — HyperText Markup Language; the code for a page's structure.
HTTPS — the secure version of a web connection; shown by the padlock.
IP address — the number that identifies a computer on the internet.
JavaScript (JS) — the code for how a page behaves when you interact with it.
Live / production — the real public website everyone sees.
Local — on your own computer, visible only to you.
Main — the main line of a project's history; what's on the live site.
Merge — joining a branch's changes into main.
Plugin — an add-on that gives a WordPress site extra features.
Preview — a private test copy of a site with its own link.
Pull request (PR) — a request on GitHub to merge a branch into main, showing every change.
Push — sending your commits from your computer up to GitHub.
Registrar — a company that sells (rents out) domain names.
Repository (repo) — a project folder tracked by Git, with its full history.
Roll back / revert — going back to an earlier version that worked.
Server — an always-on computer that sends website files to visitors.
Static site — a site that sends the same files to every visitor. Fast and safe.
Tag — an HTML label in angle brackets, like <h1>.
Version — one saved state of a project at a point in time.
Website builder — an all-in-one, drag-and-drop tool that designs and hosts sites (Webflow, Shopify).
