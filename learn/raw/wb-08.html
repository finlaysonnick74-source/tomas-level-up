07 · Deployment

From your laptop
to the whole world.

A deployment (or “deploy”) is the moment a new version of your website gets published to the internet. With the modern setup, it happens automatically.

Local — on your own computer. A local version is just for you; nobody else can see it.

Build — the step where a host takes your code and gets it ready to publish (for example, shrinking images and bundling files).

Preview — a temporary, private copy of the site with its own link, made for checking changes before they go live.

Live (or production) — the real, public website on the real domain.

The magic bit: once it's set up, you never “upload” anything. Merge on GitHub and Netlify does the rest. If a deploy ever goes wrong, Netlify keeps old deploys too, so you can switch back with one click.
