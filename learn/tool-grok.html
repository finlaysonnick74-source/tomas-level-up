🧰 Grok Bot

What it is

Your own AI building partner. You describe what you want in plain English, and it writes, changes and explains code.

Why you’ll use it

It’s how you’ll build every page of your business site, fix bugs, and ask “why does this work?” as often as you like.

Step-by-step setup

  1. With Dad, set up your own Grok Bot instance and give it a name you like.
  2. Open a chat and introduce yourself and your project: “I’m building Tomas Web Studio, a web studio for Northern Beaches businesses.”
  3. Learn the three-part prompt: the goal, the details (layout, colours, words) and how you’ll check it worked.
  4. Ask it to explain one line of code from Web Basics in your own words, then ask a follow-up question.
  5. Save a note of 3 prompts that worked well, to reuse later.

👨 Account note

Your Grok Bot runs on Dad’s paid plan, so Dad sets it up with you and looks after the billing.

🚀 Mini challenge

Ask Grok Bot to write a 3-sentence welcome for your homepage, then ask it for a friendlier version. Which do you like better, and why?

✅ Ready when

You can show Dad Grok Bot working at the toolkit check at the end of Day 3.
