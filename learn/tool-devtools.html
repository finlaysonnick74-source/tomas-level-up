🧰 Browser DevTools

What it is

Tools built into Chrome (right-click, then Inspect) that show the code behind any page.

Why you’ll use it

You can peek at how any website is built, test your site at phone size and check its speed.

Step-by-step setup

  1. Open any website in Chrome.
  2. Right-click a heading and choose Inspect.
  3. Change the heading text in DevTools (only you can see it).
  4. Switch to phone view with the device toolbar.
  5. Run a Lighthouse check on your GitHub Pages site.

👨 Account note

Built into the browser, so there’s no account needed.

🚀 Mini challenge

Inspect a local business website and find the colour code of its main button.
