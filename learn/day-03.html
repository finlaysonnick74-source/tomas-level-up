📚 The lesson

Word of the day: Repo: short for repository: the folder on GitHub that holds all your project’s files and their history.

Guided tool lessons: what each tool is, why you use it, step-by-step setup and a mini challenge.

  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.
  • GitHub: A website that keeps your code safe online, with every version saved.
  • Cursor: A code editor with AI built in, where you open your project, read the code and make changes.
  • Netlify: A host that puts your site online and updates it every time you push to GitHub.
  • Canva: An easy design app with templates for logos, images and social posts.
  • Mobbin: A huge library of screenshots from real, well-designed apps and websites.
  • Figma: A design tool pros use to lay out pages before they are built.
  • Browser DevTools: Tools built into Chrome (right-click → Inspect) that show the code behind any page.
  • Squoosh: A free Google web app that makes image files smaller without looking worse.

✅ Show Dad: toolkit check

To finish, show Dad each tool working. It’s a celebration of what you’ve set up, not a test.

  1. Show your Grok Bot and a prompt you’re proud of.
  2. Open your GitHub repo and walk through your commits.
