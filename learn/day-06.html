📚 The lesson

Word of the day: Call to action (CTA): the main button you want visitors to press, like “Get a free check”.

How to write a great prompt: the goal, the layout, your colours and fonts. Grok Bot builds the first skeleton. Then: What a hero section and a CTA are. Build the hero: headline, one-line promise, the free-check button.

  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.
  • GitHub: A website that keeps your code safe online, with every version saved.
  • Browser DevTools: Tools built into Chrome (right-click → Inspect) that show the code behind any page.
  • Canva: An easy design app with templates for logos, images and social posts.
  • Squoosh: A free Google web app that makes image files smaller without looking worse.

❓ Quick quiz

1. What does HTML do?

It's the structure and content: headings, text, images, buttons.

2. What does CSS do?

It's the style: colours, fonts, spacing and layout.

3. What is a hero section?

The big first section at the top that says what you do.

4. What is a CTA?

A call to action: the main button you want visitors to press.
