📚 The lesson

Word of the day: SEO: search engine optimisation: making a site easy for Google to understand, so the right people find it.

SEO basics: titles, descriptions, headings, and alt text (descriptions of pictures). Make a share image in Canva.

  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.
  • Browser DevTools: Tools built into Chrome (right-click → Inspect) that show the code behind any page.
  • Canva: An easy design app with templates for logos, images and social posts.
