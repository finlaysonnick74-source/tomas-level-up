📚 The lesson

Word of the day: Release: a finished, numbered version of a site (like v1.0) that’s ready to go live.

Why pros never skip a launch checklist: links, forms, spelling, phones, speed, the “page not found” page.

  • Browser DevTools: Tools built into Chrome (right-click → Inspect) that show the code behind any page.
  • GitHub: A website that keeps your code safe online, with every version saved.
  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.

So nothing important gets missed under pressure.

2. What's one thing to check twice?

Prices, contact details and anything about another business.

3. What is a broken link?

A link that leads to a missing page or error.
