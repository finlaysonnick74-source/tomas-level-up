Word of the day: Prompt: the instructions you give an AI. Clear, specific prompts get much better results.

How to write a great prompt: the goal, the layout, your colours and fonts. Grok Bot builds the first skeleton.

  • Grok Bot: An AI assistant that writes and changes code when you describe what you want.
  • GitHub: A website that keeps your code safe online, with every version saved.
  • Browser DevTools: Tools built into Chrome (right-click → Inspect) that show the code behind any page.

❓ Quick quiz

1. What does HTML do?

It's the structure and content: headings, text, images, buttons.

2. What does CSS do?

It's the style: colours, fonts, spacing and layout.

3. What does JavaScript do?

It adds behaviour: things that move, respond to clicks or update.

4. What makes a good prompt?

A clear goal, the layout, your colours and fonts, and specifics.
