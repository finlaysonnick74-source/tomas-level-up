❓ Quick quiz

1. What is a wireframe?

A plain sketch of where things go on a page, with no colours or photos.

2. What does 'mobile first' mean?

Design for the phone screen first, then expand for bigger screens.

3. What is a hex code?

A 6-character colour code like #FF5A36 so a colour looks the same everywhere.

4. What is a favicon?

The tiny icon in the browser tab.
