Web Basics · Lesson 4 of 11 · Hosting options compared

Where can a website live?

There are two main families. Code hosts publish the code you (and Grok Bot) write. Website builders are all-in-one: you design by dragging and dropping, and they host it too.

The options at a glance

Code host

Netlify Your pick

Hosts sites straight from GitHub and rebuilds them every time you save a change.

💲 Free starter plan; paid plans available. Check current pricing.

Code host

Vercel

Very similar to Netlify, made by the team behind a tool called Next.js.

💲 Free for personal use; paid for business. Check current pricing.

Code host

GitHub Pages

Free hosting built into GitHub itself.

💲 Free with a GitHub account (public projects).

Code host

Cloudflare Pages

Hosting on Cloudflare's huge, fast global network.

💲 Free tier; paid add-ons. Check current pricing.

Website builder

Webflow

A visual designer that writes the code for you, with hosting included.

💲 Paid site plans. Check current pricing.

Website builder

WordPress

The most widely used website system in the world, with thousands of add-ons called plugins.

💲 Software free; hosting costs extra. Check current pricing.

Website builder

Shopify

A builder made specifically for online shops.

💲 Monthly subscription plus payment fees. Check current pricing.

Tomas's rule of thumb

Brochure-style business site (cafe, plumber, surf school)? Grok Bot + GitHub + Netlify. Client wants to sell products online? Look at Shopify.
