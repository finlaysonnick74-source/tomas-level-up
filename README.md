# Tomas Levels Up (private family site)

Live: https://finlaysonnick74-source.github.io/tomas-level-up/ · Business site: https://finlaysonnick74-source.github.io/tomas-web-studio/

Light privacy screen only: the passcode (levelup2026) is in gate.js, and the site is public on GitHub Pages. noindex + robots.txt keep it out of search engines.

## Daily update (2 minutes)
1. Open `progress.json`, find today's day.
2. Set `status` to `"progress"` when you start, `"done"` when you finish.
3. Fill `built`, `learned`, `proud` (answer the day's reflection prompt) and paste your `commit` link. Dad can add `dad_note`.
4. `git add progress.json && git commit -m "Day N done" && git push`
5. About a minute later the tracker (calendar, progress bar, streak) updates by itself.

To tick an outcome or a skill, change `st upcoming` to `st done` in tracker.html / outcomes.html / learning.html.
Lesson pages are generated by `build.py` + `curriculum.py` from the Web Basics guide and the 21-day plan.

## Wall of support
1. Family and supporters use **wall.html**: a message, advice, or a pick-a-card treat offer with a milestone and "when".
2. Pressing Post puts it straight on the wall. It also shows on the supporters' home page, Tomas's Today page and his dashboard ("Messages from your crew").
3. Posts are stored in a free, no-login key-value store (keyvalue.immanuel.co, app key `WALL_KEY` in `zones.py`). Light spam protection: a hidden honeypot field, a 500-character limit and a short cooldown between posts.
4. `wall.json` holds pinned messages that always show alongside the live posts.
5. To remove a post, set its `m<number>` key to 0: `curl -X POST -H 'Content-Length: 0' https://keyvalue.immanuel.co/api/KeyVal/UpdateValue/<WALL_KEY>/m<number>/0`
